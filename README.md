## ⏱️ Complexity Reference

Understanding **time and space complexity** is an essential part of designing efficient algorithms and evaluating solutions.

### Time Complexity

| Complexity | Classification | Typical Example |
|:---:|:---|:---|
| `O(1)` | Constant | Array Access |
| `O(log n)` | Logarithmic | Binary Search |
| `O(n)` | Linear | Linear Search |
| `O(n log n)` | Linearithmic | Merge Sort |
| `O(n²)` | Quadratic | Bubble Sort |
| `O(2ⁿ)` | Exponential | Subset Generation |
| `O(n!)` | Factorial | Permutation Generation |

### Space Complexity

Space complexity describes the amount of **additional memory** an algorithm requires as the input size grows.

| Complexity | Classification | Typical Example |
|:---:|:---|:---|
| `O(1)` | Constant Space | In-place swap |
| `O(log n)` | Logarithmic Space | Recursive Binary Search |
| `O(n)` | Linear Space | Auxiliary Array |
| `O(n²)` | Quadratic Space | 2D Matrix |

> A good solution should aim for an appropriate balance between **execution time** and **memory usage**.

## 🧠 Problem-Solving Workflow

A structured workflow helps turn a problem statement into a correct, efficient, and maintainable solution.

```text
┌─────────────────────────────┐
│    Understand the Problem   │
└──────────────┬──────────────┘
               ↓
┌─────────────────────────────┐
│     Identify Constraints    │
└──────────────┬──────────────┘
               ↓
┌─────────────────────────────┐
│   Develop a Brute-Force     │
│          Approach           │
└──────────────┬──────────────┘
               ↓
┌─────────────────────────────┐
│ Analyze Time & Space        │
│        Complexity            │
└──────────────┬──────────────┘
               ↓
┌─────────────────────────────┐
│    Find an Optimization     │
└──────────────┬──────────────┘
               ↓
┌─────────────────────────────┐
│    Implement the Solution   │
└──────────────┬──────────────┘
               ↓
┌─────────────────────────────┐
│      Test Edge Cases        │
└──────────────┬──────────────┘
               ↓
┌─────────────────────────────┐
│    Review & Refactor Code   │
└─────────────────────────────┘
```

### ✅ Problem-Solving Checklist

- Understand exactly what the problem asks.
- Identify input size and constraints.
- Determine the required output.
- Consider edge cases and boundary conditions.
- Start with a straightforward solution.
- Analyze its time and space complexity.
- Look for a better data structure or algorithm.
- Implement clean and readable code.
- Test normal, edge, and worst-case inputs.
- Review the final solution for correctness and efficiency.
